1. Introdução

O Sistema de Ponto Eletrônico foi desenvolvido para facilitar o controle de jornada de trabalho dos funcionários, permitindo registro de pontos, gestão de funcionários, geração de relatórios e muito mais.

Dica: Mantenha sempre o sistema atualizado e faça backups regulares dos dados.

2. Acesso ao Sistema

1 Acessar URL do sistema

Abra seu navegador e digite o endereço do sistema:

https://divulgpontofacil.com.br

2 Fazer login

Digite suas credenciais de administrador:

  • Email/CPF: Seu email cadastrado
  • Senha: Sua senha de acesso
Atenção: Mantenha sua senha em local seguro e troque periodicamente.

3. Dashboard

O Dashboard é a tela inicial após o login, onde você pode visualizar informações importantes do sistema.

Principais indicadores:

  • Total de funcionários: Quantidade de funcionários ativos
  • Pontos registrados hoje: Total de marcações do dia
  • Funcionários ausentes: Quem não bateu ponto hoje
  • Horas trabalhadas: Média de horas no mês
Dica: Use os gráficos para acompanhar tendências e identificar problemas rapidamente.

4. Gerenciar Funcionários

4.1 Cadastrar novo funcionário

  1. Clique em "Funcionários" no menu lateral
  2. Clique em "Novo Funcionário"
  3. Preencha os dados obrigatórios:
    • Nome completo
    • CPF (apenas números)
    • Email
    • Data de nascimento
    • Cargo
    • Salário base
    • Horário de trabalho
  4. Clique em "Salvar"

4.2 Editar funcionário

  1. Vá em "Funcionários"
  2. Localize o funcionário na lista
  3. Clique no ícone (Editar)
  4. Altere os dados necessários
  5. Clique em "Atualizar"

4.3 Excluir/Desativar funcionário

  1. Vá em "Funcionários"
  2. Clique no ícone (Excluir)
  3. Confirme a exclusão
Nota: A exclusão é lógica (soft delete), os dados ficam preservados no sistema.

5. Gerenciar Filiais

5.1 Cadastrar filial

  1. Clique em "Filiais"
  2. Clique em "Nova Filial"
  3. Preencha os dados:
    • Nome da filial
    • CNPJ
    • Endereço completo
    • Telefone
    • Email
  4. Clique em "Salvar"

5.2 Atribuir funcionários à filial

  1. Vá em "Funcionários"
  2. Edite o funcionário
  3. Selecione a filial no campo "Filial"
  4. Salve as alterações

6. Gerenciar Pontos

6.1 Visualizar pontos dos funcionários

  1. Clique em "Pontos" no menu
  2. Selecione o funcionário desejado
  3. Escolha o período (dia, semana, mês)
  4. Visualize a lista de marcações

6.2 Ajustar ponto manualmente (correção)

  1. Vá em "Pontos" > "Ajustes"
  2. Selecione o funcionário
  3. Clique em "Novo Ajuste"
  4. Informe a data e horário correto
  5. Justifique o ajuste
  6. Clique em "Salvar Ajuste"
Importante: Todo ajuste fica registrado em auditoria para conformidade legal.

7. Relatórios

Relatórios disponíveis:

Relatório Descrição Exportação
Espelho de Ponto Detalhamento diário das marcações PDF / Excel
Horas trabalhadas Resumo mensal de horas PDF / Excel
Funcionários ausentes Lista de faltas e atrasos Excel
Relatório de ajustes Histórico de correções de ponto PDF

Como gerar relatório:

  1. Clique em "Relatórios"
  2. Selecione o tipo de relatório
  3. Escolha o período (data inicial e final)
  4. Selecione funcionário (ou todos)
  5. Clique em "Gerar Relatório"
  6. Exporte em PDF ou Excel

8. Backup e Segurança

8.1 Realizar backup manual

  1. Clique em "Backup" no menu
  2. Clique em "Criar Novo Backup"
  3. Aguarde a conclusão
  4. Download do arquivo gerado

8.2 Restaurar backup

  1. Vá em "Backup" > "Restaurar"
  2. Selecione o arquivo de backup
  3. Confirme a restauração
Cuidado: Restaurar backup irá sobrescrever todos os dados atuais!

Boas práticas de segurança:

  • ✔ Faça backup diário dos dados
  • ✔ Mantenha o sistema atualizado
  • ✔ Use senhas fortes (mínimo 8 caracteres, letras, números, símbolos)
  • ✔ Não compartilhe suas credenciais
  • ✔ Monitore os logs de acesso regularmente
